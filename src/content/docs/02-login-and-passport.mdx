## 從 Telegram 開始

正式登入流程會從你的小隊 Telegram 群組開始。

在小隊群裡輸入：

<CodeBlock title="Telegram 小隊群">

```text
vip-666
```

</CodeBlock>

Bot 會刪掉你的訊息，然後在群組裡產生一個只給你使用的按鈕。你點按鈕後，Bot 會帶你到私人聊天，傳給你遊戲登入連結。

這個群組按鈕背後的登入請求目前有效時間是 10 分鐘。真正的登入 token 不會出現在小隊群裡，只會在 Bot 私訊給你的登入連結或備用 token 中出現。

登入連結和 token 都是你的個人入口，不要轉傳給別人。瀏覽器成功登入後，系統會在你的裝置上寫入登入 cookie，之後通常不需要每次都重新走 Telegram 流程。

<Callout>如果登入連結失效，回到自己的小隊 Telegram 群重新輸入 vip-666，再走一次流程。</Callout>

## 你會被綁定到小隊

系統會依照你在哪個 Telegram 小隊群觸發登入，把你綁到對應小隊。

如果你已經建立過帳號，再次登入通常會沿用原本帳號，不會因為重新輸入一次就變成另一個人。

每個 Telegram 使用者只會對應到一個玩家帳號。小隊群和遊戲小隊的對應由 Staff 事先設定，如果在錯誤群組觸發登入，請找 Staff 確認。

## 個人 QR Code 是做什麼的

遊戲裡的「冒險者通行證」會顯示你的個人 QR Code。

這個 QR Code 通常是給 Staff 或隊輔掃描，用來發放你完成活動、回答問題或參與任務後的獎勵。

請注意：個人 QR Code 不是社群攤位 QR Code。攤位 QR Code 是你去掃別人的；個人 QR Code 是讓工作人員掃你的。

## 暱稱和頭像

你可以在遊戲裡調整暱稱。

頭像可以使用你已經擁有的小石圖示。也就是說，你收集到的小石越多，可以拿來當頭像的選擇也越多。

小隊頭像也可以設定，但它使用的是整個小隊中至少一位隊員擁有的小石圖示，不限定只能用你自己的小石。

## 登出和換裝置

如果你需要在另一台裝置登入，最穩定的方式是回到小隊 Telegram 群重新輸入 vip-666，取得新的登入連結。

如果你登出目前瀏覽器，只是清掉這台裝置的登入狀態，不會刪除你的玩家資料、小石、道具或開源力。
