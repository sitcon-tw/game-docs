## 先記住三句話

這個遊戲的重點不是躲在角落一直刷分，也不是只看誰答題最快。

你可以把它想成一張營隊冒險紀錄卡：你參加課程、回答問題、逛社群攤位、跟隊友互動、完成活動，就會慢慢累積小石、道具和開源力。

最重要的三件事是：

- 小石：代表你在營隊裡累積的經歷，也可以帶去知識王戰。
- 開源力：像遊戲中的資源，可以買道具、推進合成。
- 小隊：排行榜會看整隊的平均成果，不是只看一個人衝很高。

## 現在遊戲裡有哪些地方

登入後，你會看到幾個主要入口：

| 入口 | 可以做什麼 |
| --- | --- |
| 首頁 | 看自己的開源力、小石數、道具數、小隊排名和目前可用行動 |
| 戰鬥 | 建立現場配對、加入多人房，或在開放時打電腦戰 |
| 小石 | 查看小石收藏、設定出戰組合、進入合成 |
| 商店 | 用開源力購買素材、御守或其他道具 |
| 通行證 | 顯示個人 QR Code、掃描攤位或獎勵 QR Code、調整暱稱與頭像 |
| 排行榜 | 看小隊榜、個人榜、隊員狀態與玩家收藏 |
| 公開圖鑑 | 瀏覽目前遊戲內容，不一定需要擁有才看得到 |

## 每天可以做什麼

你不需要一開始就研究所有規則。先照這個順序玩就好：

1. 登入遊戲，確認自己在正確的小隊。
2. 看看自己有哪些小石。
3. 找人打一場知識王戰，或加入多人房熟悉答題流程。
4. 去商店看看能買什麼道具。
5. 如果材料夠，就嘗試合成新的小石。
6. 逛社群攤位時，記得用遊戲內掃描 QR Code。
7. Staff 或隊輔發獎時，打開自己的 QR Code 或掃描對方提供的獎勵 QR Code。
8. 回排行榜看看自己和小隊目前差多少。

## 有些功能會依現場設定開關

對戰不一定每個時段都能開局。後台可以設定上課時間鎖定、強制開放、強制關閉或維護模式。

電腦戰和多人房電腦補位也都是可設定功能。如果畫面上顯示不能使用，不代表帳號壞掉，通常是當下活動設定暫時不開放。

## 不用太焦慮排名

排行榜會顯示小隊和個人的成果，但它不是要讓大家變成只會算分的機器。

這個系統真正想鼓勵的是：多問一個問題、多認識一個社群、多跟隊友合作一次、多把學到的東西留下來。

如果你不知道現在要做什麼，最簡單的答案是：去參與營隊本來就希望你參與的活動。
