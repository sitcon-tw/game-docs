## 展示不是念功能清單

好的展示會先說使用者是誰、他遇到什麼問題、你的作品如何幫他完成一件事。功能清單可以放後面，先讓觀眾知道為什麼要看。

如果你的作品包含 AI 助教，請展示一個正常輸入與一個高風險輸入，說明系統如何提示與處理。

## 交付前檢查

請至少檢查三種尺寸：手機寬度、筆電寬度、投影機或大螢幕。前端作品常常在自己的螢幕看起來正常，換尺寸就出現文字擠壓或按鈕太小。

最後確認所有按鈕有作用、表單有提示、外部連結能開啟。能解釋的作品，比只看起來完整的作品更有價值。

<CodeBlock title="展示講稿骨架">

```text
1. 這個作品是給誰使用？
2. 使用者會先看到什麼？
3. 使用者可以做哪一個關鍵互動？
4. 我在哪裡處理了安全或錯誤狀態？
5. 如果有更多時間，我會改進哪一部分？
```

</CodeBlock>
