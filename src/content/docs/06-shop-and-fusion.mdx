## 商店能買什麼

商店主要會賣三類東西：

- 合成素材：用來讓小石進化。
- 御守：買了之後永久生效，但要搭配對應類型小石上場。
- 裝飾道具：主要是收藏或紀念用途。

購買會花掉開源力。

## 有些商品會顯示但不能買

如果商品是 locked，代表它目前尚未開放購買。

如果商品沒有出現在商店，可能是：

- 它不是商店商品。
- 它目前未啟用。
- 它是活動、攤位或 Staff 發獎才會取得的材料。

不要看到合成缺材料就急著找商店。有些材料本來就要透過活動取得。

## 同一個商店商品通常只能買一次

目前系統會記錄你買過哪些商品。

同一位玩家對同一個商店商品只能購買一次。購買前可以先想一下：這個材料是不是你現在最想合成的路線需要的？

## 合成是消耗材料換新東西

合成不是複製，也不是免費升級。

當你合成時，配方需要的 input 會被扣掉，output 會加入你的背包。

常見配方長這樣：

<CodeBlock title="常見合成路線">

```text
基礎小石 + 合成素材 -> 普通小石
普通小石 + 進階素材 -> 稀有小石
```

</CodeBlock>

例如某條工程路線可能會從工程型小石開始，先變成 Docker 小石，再繼續變成 Kubernetes 小石。

<Callout>合成會消耗原本的小石和道具。按下合成前，先確認這就是你想走的路線。</Callout>

## 基礎小石和活動小石不是玩家合成出來的

你會在合成列表看到有些資料代表基礎小石或活動限定小石，但它們不是開放給玩家主動合成的配方。

基礎小石通常來自初始發放、對戰掉落或 Staff 發獎。

活動限定小石通常來自特殊活動、闖關、夜談或 Staff 發獎。

## 自動補材料只是輔助

有些頁面可能提供「補齊缺少材料」之類的操作。

它只是幫你自動購買或自動走可推導的合成路線，不會憑空變出材料。材料沒開放、已鎖定、買過了、開源力不夠，或合成路線不明確時，都可能無法自動補齊。
