## 先跑最小檢查

不要一開始就安裝一堆工具。先確認終端機能執行指令、Node 有版本、專案能啟動。每一步只驗證一件事，比較容易找出問題。

<CodeBlock title="終端機檢查">

```bash
node -v
npm -v

# 如果上面兩行都有印出版本號，代表基本環境可用。
# 接著進入你的專案資料夾，再啟動開發伺服器。
npm install
npm run dev
```

</CodeBlock>

## 錯誤回報要包含三個資訊

卡住時不要只說「不能跑」。請留下你做了什麼、畫面看到什麼、終端機第一段錯誤是什麼。這樣助教可以直接判斷是路徑、套件、語法還是瀏覽器問題。

好的錯誤回報本身就是工程能力的一部分。它會讓你更快得到能用的答案。

<Callout>回報格式：我執行的指令、我期待看到的結果、實際出現的錯誤訊息。</Callout>
