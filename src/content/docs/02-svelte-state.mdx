## 狀態是畫面的記憶

前端不是只有把文字排出來。只要使用者能點擊、輸入、切換，畫面就需要記住目前發生了什麼。這個記憶就是狀態。

Svelte 5 的 runes 把狀態寫得很直接：你宣告一個值，使用者操作時改變它，畫面會跟著更新。

<CodeBlock title="完成按鈕元件">

```svelte
<script>
  // $state：宣告響應式狀態，值改變時畫面會自動更新。
  let finished = $state(false);

  // toggleFinished：按鈕被點擊時執行，切換完成狀態。
  function toggleFinished() {
    finished = !finished;
  }
</script>

<button on:click={toggleFinished}>
  {finished ? '已完成本章' : '標記本章完成'}
</button>
```

</CodeBlock>

## 先做能被驗證的小互動

不要一開始就做整個網站的所有互動。先做一個按鈕、一個輸入框、一個章節切換。當你確認資料與畫面有連動，再把同樣方法擴大到更多元件。

這份 docs 右側的「標記本章完成」就是同一種概念：點擊之後狀態改變，章節清單與按鈕文字一起更新。
